# 传统文化资料库（第一批）

这里是塔罗项目的传统文化资料入口，不是把整部古籍直接塞进浏览器，也不是一个“万能算命提示词”。资料、规则和模型解释必须分层：

1. `manifest.json`：每个来源的标题、链接、版本说明、版权注意事项和当前状态。
2. `rules/`：只写可审计的规则契约；标记为 `candidate` 的内容，在全文校对前不能作为线上计算结果。
3. `pipeline/PIPELINE_STATE.md`：记录蒸馏流水线做到哪一步，避免以后混用未核验材料。

## 首轮范围

- 《周易》：经文和传篇作为卦辞、爻辞的出处层。
- 《梅花易数》：象数、起卦、互卦、变卦、体用和五行的规则层。
- 《道德经》《庄子》：只做“道家观照”与反思问题，不宣称进行宗教仪式。
- 《渊海子平》《三命通会》：先建立四柱命盘输入和规则接口，待校对后再启用排盘。
- 奇门遁甲已经以《神奇之门》的“时家奇门·拆补法”资料层接入，但节气交接仍是近似日，临界时刻需要万年历复核。
- 八宅风水已经以《八宅风水简介》的坐向—宅卦—东/西四宅—四吉四凶框架接入；没有明确房屋朝向时不猜宅卦。
- 紫微斗数、太乙、大六壬等仍列入后续阶段，暂不与当前结果混算。

## 上线约束

- 排盘、换算和卦数计算由本地确定性代码完成；Qwen 只负责解释已经算出的结构。
- 任何原文引用都要带 `sourceId`、章节/位置和版本；模型不能自行补写“出处”。
- 现代白话、注释、课程和软件规则不能因为古籍公有领域就直接复制。
- 解读统一使用“传统文化观照/可能性”措辞，不对疾病、法律、财务或人生做确定性判断。

梅花试点已完成五份技能、独立行为盲测和数值脚本检查，见 `books/meihua-yishu-wikisource/INDEX.md`。奇门和八宅的本轮资料包分别见 `books/shenqi-zhimen/` 与 `books/bazhai-fengshui-brief/`，网站只把确定性结构传给 Qwen；原文、现代白话和未核实说法保持分层。
