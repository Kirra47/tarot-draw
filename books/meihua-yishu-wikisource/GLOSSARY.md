# 梅花易数共享术语

| 术语 | 本包采用的含义 |
|---|---|
| 八卦数 | 乾1、兑2、离3、震4、巽5、坎6、艮7、坤8 |
| 先天/后天 | 数先于卦、象先于取数等方法差别，不等于时间/非时间两类 |
| 年支数 | 子1至亥12；不是公历年份 |
| 时支数 | 子1至亥12；时区及转换策略另行确定 |
| 初爻/上爻 | 最下/最上爻；数组按初爻到上爻排列 |
| 动爻 | 单次梅花结构中翻转阴阳的一爻，位置1–6 |
| 互卦 | 下卦二三四爻，上卦三四五爻；纯乾坤另有取变卦互的分支 |
| 变卦 | 只改变指定动爻后的六爻结构 |
| 体用 | 本版以动爻所在三爻卦为用，另一卦为体；体主、用事 |
| 用生体/体生用 | 相生方向不同，不能交换；金生水、水生木、木生火、火生土、土生金 |
| 用克体/体克用 | 相克方向不同；金克木、木克土、土克水、水克火、火克金 |
| 比和 | 两卦同属一五行 |
| 旺衰 | 传统时令条件，缺日期或月令策略时不判断 |
| 三要 | 耳、目、心，即听、看、思；据卷二三要灵应篇更正旧候选 |
| 十应 | 现场类象分类标题；展开类别超过十种，按原章节保留 |
| 克应 | 本包只接受用户主动提供的环境事件，事实与象征解释分栏 |
| 应期 | 传统应验时间解释；本包没有保证日期功能 |
| V2 | 新输入的规则推演检查，不是现实事件预测准确率 |

来源：[卷一](https://zh.wikisource.org/wiki/梅花易數/卷一)、[卷二](https://zh.wikisource.org/wiki/梅花易數/卷二)。具体实现约定见 RULE_NOTES.md。
