# 梅花易数候选术语表

> 阶段 1 原始候选池。定义采用自己的话重写，原文位置只用于追溯，不把术语解释扩展成未经来源支持的新规则。

| 术语 | 可执行定义 | 原文位置 |
|---|---|---|
| 八卦 | 以三爻结构表达基本象与关系，并有数、方位、五行和类象映射 | 卷一“周易卦数”“八卦象例”“八卦类象” |
| 先天之数 | 先从时间、数量等数取得卦，再解释卦象；核心是“由数入卦” | 序；卷二“先天后天论” |
| 后天之数 | 先由物象、声音或既成卦类得到卦，再配合时间和《易》辞 | 序；卷一“物卦起例” |
| 上卦/下卦 | 重卦的上、下两个三爻卦；不同起卦方法分别决定其来源 | 卷一“年月日時起例”“物数占例” |
| 卦以八除 | 起卦数按八循环取余对应八卦，余零按八处理 | 卷一“卦以八除” |
| 动爻 | 重卦总数按六循环取余得到的变化爻，阴阳翻转后形成变卦 | 卷一“爻以六除” |
| 互卦 | 去掉初爻和上爻，用中间四爻组成内在卦象，常作事情中段线索 | 卷一“互卦起例”；卷三“体用互变之诀” |
| 变卦 | 动爻翻转后得到的卦，常作事情后段或变化方向线索 | 卷一“爻以六除”；卷三“变卦式八则” |
| 体/用 | 体是所问之主，用是所问之事或外部作用；动静决定常见划分 | 卷二“占卜总决”“体用总诀” |
| 生克/比和 | 用五行相生、相克或同类关系描述体用及互变之间的作用方向 | 卷一“五行生克”；卷二“体用生克篇” |
| 卦气旺衰 | 以季节和月份判断卦所对应五行的强弱条件 | 卷一“卦气旺”“卦气衰”；卷三“体用衰旺之诀” |
| 克应 | 将占时真实出现的人事、物件、声音、颜色、方位等作为辅助验证线索 | 卷二“占卜总决”“十应奥论” |
| 三要 | 耳、目、心：听、看、思；天时、地理、人事属于观察对象 | 卷二“三要灵应篇”（2026-09-07 按原文更正） |
| 十应 | 将天时、地理、人事、时令、方卦、动物、静物、言语、声音、五色、写字等应象分类观察 | 卷二“十应奥论”“十应目论” |
| 活法 | 规则必须结合问题语境和现实理路变通，不能执着于单一类象 | 卷二“心易占卜玄机”“占卜总决” |
