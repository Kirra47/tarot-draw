# 梅花体用关系解释

## R — 原文

> 體用即動靜之說。體為主，用為事。

出处：[卷二·占卜總決](https://zh.wikisource.org/wiki/梅花易數/卷二)。这是公开传本文本；作者归属和出版年未锁定。

## I — 方法论骨架

先确认体用对应哪个卦和哪个现实角色。
乾兑金、震巽木、坎水、离火、坤艮土构成关系表。
分别计算他卦生体、体生他卦、克体、体克和比和。
这些关系是传统解释符号，不是现实效应量。
已有时令规则才补旺衰，缺时令就保留未判定。
把支持与阻力翻译成可核查的问题，不合成为成功概率。

## A1 — 书中的应用

牡丹占：书中以巽木为体、乾金克体，并参考互卦重乾，解释外部克制集中，继而叙述花被马践毁。这里沿用的是体用关系演示，不能把乾金固定解释为马，更不能据此预报财物损失。

## A2 — 触发场景

1. 已给体用卦，想理解生克方向。
2. 给出互变结果，要求比较支持和消耗。
3. 明确提供月令及规则表，要求把旺衰作为附加条件。

语言信号：“体用怎么看”“用生体还是体生用”“body-use analysis”。

与相邻技能区分：hexagram-structure 算体用位置；本技能消费其结果。context-log 记录环境，本技能不虚构外应。

## E — 可执行步骤

1. 确认body/use及互变来源；角色缺失先补结构，不以用户期望更换体用。完成标准是体用卦号/五行确定。
2. 用相邻numeric技能脚本的relation(body,other)分别计算。其他卦可用同函数，但展示时把“用”替换成具体参与者名称。五种关系必须区分，尤其体克用不等于用克体。
3. 时令缺失输出未判旺衰；明确时令时按已给出处表逐项说明，不把未知日期代换为当前季节。先天取数模式不强制先查爻辞；欲附原文须实际检索并标来源。
4. 给出关系、传统解释、现实核查问题各一栏，针对用户普通问题给一个可逆行动。高风险问题保留文化说明，现实建议以实际资料为依据。

## B — 边界

不输出由生克推得的成功率、患病概率或保证日期。书中的阴阳性别类象不可作为对真实人的判断。道家哲学、八字用神与本技能的五行关系分开标注。

原书提醒“以理论之”及结合情境变通；历史占例有选择性叙述，传统符号关系不能当作现实因果证据。
