# 梅花观察输入与取数

## R — 原文

> 起數又須明理。

出处：[卷一·鄰夜扣門借物占](https://zh.wikisource.org/wiki/梅花易數/卷一)。这是公开传本文本；作者归属和出版年未锁定。

## I — 方法论骨架

观察值先于解释。
数件物品、数次声响、字数、笔画和古声调是不同输入。
保留用户原话与所用取数法，避免一次解读中换算法。
两个声组分别取卦与单个声次数配时法要分开。
文字存在简繁、笔画和音韵差异，首版只记录并指出待定方案。
已确定的数值可以交给数值技能计算。

## A1 — 书中的应用

邻夜扣门借物：书中记述先一声、后五声，乾上巽下，加酉时十得十六，四爻动。父子从金短木长得到锄/斧候选，再用冬夜劈柴场景选择斧，来人所借也是斧。该例说明两个声组法不同于单次声数配时法。

## A2 — 触发场景

1. 用户提供真实物件或声组，要求以它们起梅花卦。
2. 用户要求说明一句话究竟按字数还是笔画取数。
3. 用户要求保存输入以便复算，尚未选定计数方案。

语言信号：“用这几声起卦”“用这句话字占”“取象 / observation input”。

与相邻技能区分：numeric-cast 负责算已给数字；context-log 只记已有卦的外部背景。本技能负责新起卦之前的观察到数值转换。

## E — 可执行步骤

1. 记录用户实际描述、输入类型、发生时间（若已知）；将事实与类象联想分栏。没有观察资料时停止取象。
2. 可数物/单声数配时，或明确的两声组加时，各自记录计数方式。两声组法上卦cycle(a,8)、下卦cycle(b,8)、动爻cycle(a+b+时数,6)，并标出采用原数求和约定。
3. 文字只在用户明确方案且有对应原文时计算；古声调、多音字、笔画异体未定时给出需要固定的字段，不把普通话声调冒充古音。
4. 数值齐全交 meihua-numeric-cast 支持的方法；不支持的方法保留记录及公式。完成标准是事实、方法、计数、歧义和出处可区分。

## B — 边界

不对手势视频抓取吉凶征兆。该技能不录音、不启动摄像头。不把所有物数、声音都叫后天法。不通过选取有利声组或删字改变已确认输入。

原书提醒“以理论之”及结合情境变通；历史占例有选择性叙述，传统符号关系不能当作现实因果证据。
